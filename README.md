# World Clock Widget

**Находите время друг для друга, даже когда между вами несколько часовых поясов.**

World Clock Widget показывает местное время ваших коллег, клиентов и близких, помогает выбрать удобный момент для звонка и напоминает о нём. Всё важное — в небольшом окне на рабочем столе.

## Что можно делать

- **Видеть время сразу в нескольких городах.** Добавляйте нужные города, меняйте их порядок и двигайте шкалу времени, чтобы посмотреть ближайшие 24 часа.
- **Понимать, когда человеку удобно ответить.** Зелёный показывает рабочие часы, жёлтый — время, когда связаться можно, тёмный — период «Не беспокоить». У каждого города может быть своё имя и график.
- **Подбирать время для общего созвона.** «Удобно всем» ищет 30-минутный интервал для выбранных участников, отдавая предпочтение рабочим часам. Готовый список местных дат и времени можно скопировать в общий чат.
- **Не забывать о договорённостях.** Создавайте напоминания быстрым интервалом от текущего или выбранного времени, перетаскиванием либо на точную дату и время.
- **Настроить виджет под себя.** Доступны светлая и тёмная темы, русский и английский языки, формат времени, автозапуск и сочетание клавиш.

# World Clock Widget

Бесплатный виджет мирового времени для Windows и macOS. Показывает местное время людей в разных городах, их часы связи и помогает подобрать время для созвона.

**Актуальный выпуск: [v1.1.128](https://github.com/CandFlip/world-clock-widget/releases/tag/v1.1.128).** [Все возможности](docs/FEATURES.md) · [Последние изменения](CHANGELOG.md)

## Скачать и установить

### Windows 10/11 · x64

1. [Скачайте установщик EXE](https://github.com/CandFlip/world-clock-widget/releases/download/v1.1.128/WorldClockWidget-Setup-v1.1.128.exe).
2. Запустите его и пройдите шаги установки. После этого откройте World Clock Widget.

Python и команды в терминале не нужны. Если компонент WebView2 отсутствует, установщик добавит его сам.

### macOS 13+ · Apple Silicon и Intel

1. [Скачайте DMG](https://github.com/CandFlip/world-clock-widget/releases/download/v1.1.128/WorldClockWidget-macOS-v1.1.128.dmg).
2. Откройте DMG и перенесите приложение в «Программы».
3. Если macOS заблокирует первый запуск, откройте приложение один раз, затем выберите «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Mac Beta пока не имеет подписи Apple Developer ID. Это [штатный способ Apple](https://support.apple.com/102445); отключать Gatekeeper не требуется.

## Что умеет виджет

- Показывает время городов с учётом часовых поясов и переходов на летнее время.
- Позволяет выбрать базовое время и двигать шкалу на ближайшие 24 часа.
- Отмечает рабочие часы зелёным, время для связи жёлтым и период «Не беспокоить» тёмным. Для каждого города можно указать имя и отдельный график.
- Кнопка «Удобно всем» ищет время 30-минутного созвона для выбранных городов и копирует местное время каждого участника для отправки в чат.
- Создаёт напоминания от текущего или выбранного времени через настраиваемые быстрые интервалы.
- Поддерживает русскую и английскую локализацию, светлую и тёмную темы, настройку формата времени и сочетания клавиш.

Подробные сценарии и ограничения подбора времени описаны в [руководстве по возможностям](docs/FEATURES.md).

## Что изменилось в v1.1.128

Правый клик по шкале теперь возвращает текущее время и целиком сбрасывает открытую сессию: скрывает быстрые интервалы, выключает «Удобно всем» и снимает выбор городов. Обновления интерфейса и логики перенесены в Mac Beta. Список изменений начиная с v1.1.118 — в [истории версий](CHANGELOG.md).

Универсальная Mac-сборка прошла сборку, запуск и автоматические тесты на macOS 15 в GitHub Actions. Полная ручная проверка на физическом Mac ещё не проводилась.

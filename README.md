# World Clock Widget

Бесплатный виджет мирового времени для Windows. Он помогает быстро понять, который час у друзей, коллег и близких в разных городах, и подобрать удобное время для звонка или встречи.

Дополнительное Android-приложение `android-companion` получает таймеры и будильники напрямую через защищённую одноразовую QR-привязку. Telegram не используется.

## Скачать

Скачайте установщик на странице [последнего релиза](../../releases/latest) и запустите файл `WorldClockWidget-Setup-*.exe`. Python и ручная установка не нужны.

> Приложение пока не подписано цифровым сертификатом, поэтому Windows SmartScreen может показать предупреждение для нового издателя.

## Возможности

- время крупных городов мира с корректными часовыми поясами и переходами на летнее время;
- поиск городов на русском и английском языках;
- избранные города и быстрый перенос города на главный экран;
- изменение порядка карточек перетаскиванием;
- светлая и тёмная темы, русский и английский интерфейс;
- временная шкала для планирования звонков и встреч;
- напоминания с тремя интервалами, которые можно изменить в настройках;
- запоминание размера и положения окна;
- автозапуск вместе с Windows;
- показ и скрытие через трей или сочетание `Alt+Shift+T`.

Каталог крупных городов основан на данных [GeoNames](https://www.geonames.org/) и распространяется с указанием источника по лицензии CC BY 4.0.

## Как пользоваться

После установки приложение запускается автоматически и остаётся доступным в системном трее. Значок шестерёнки открывает настройки. Стрелка справа плавно убирает виджет за край экрана.

## Для разработчиков

Текущая версия использует C++/Win32 и системный Microsoft WebView2. Python-код сохранён как историческая реализация и не входит в распространяемое приложение. Актуальная база указана в `CURRENT_BASELINE.md`.

Сборка приложения:

```powershell
.\native\build_webview.ps1
```

Создание установщика выполняется сценарием `WorldClockWidget.iss` через Inno Setup.

## Системные требования

- Windows 10 или Windows 11;
- 64-разрядная система.

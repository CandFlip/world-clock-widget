# World Clock Alarm for Android

Android companion for World Clock Widget. Scan the QR shown by the Windows app once. Pending alarms are stored and scheduled locally with Android's exact alarm API. Alarm notifications and the full-screen alarm provide **Done**, **+5 minutes**, and **+15 minutes** actions. Telegram is not used.

The persistent low-priority sync notification keeps the direct encrypted device connection available for changes from Windows. After a reboot, saved alarms are scheduled again automatically.

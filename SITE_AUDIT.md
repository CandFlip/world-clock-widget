# Аудит сайта World Clock — 4 октября 2026

Цель: упростить админку, сделать единое голосование с отменой выбора и модерацией пользовательских идей, показать статистику скачиваний.

## Проверенные сценарии

1. Админка до изменений — перегружена: все служебные строки RU/EN представлены одновременно. Подтверждено текущим экраном (`audit-20261004/01-admin-before.png`) и DOM. Исправление: разделы задач, один язык редактирования, только пять содержательных полей главной страницы и три поля истории. Общие параметры планов не дублируются по языкам.
2. Голосование — раньше выбранную карточку нельзя было отменить. Теперь повторное нажатие снимает голос через DELETE с проверкой сессии и Origin. Повторная отмена безопасна. Изменение голоса остаётся доступным. Проверено локальным API-тестом.
3. Предложение идеи — раньше статус published выводил текст в отдельном блоке без голосования. Теперь одобренные идеи становятся обычными карточками общей доски, с постоянным ID и голосами. До одобрения автор видит приватный статус. Скрытие сохраняет текст и голоса; повторная публикация возвращает прежние голоса. Проверено локальным API-тестом. Реальные пользовательские идеи при QA не создавались и не менялись.
4. Планы — одинаковые поля названия, описания и статуса, необязательная цель сбора для любой карточки. Скрытие вместо удаления сохраняет голоса. Отсутствующий перевод использует имеющийся текст. Проверено тестами модели; визуальные проверки новой версии описываются в отдельном итоговом отчёте.
5. Статистика — в существующей D1 базе таблицы событий скачивания нет. Добавлены агрегаты по дню UTC, Windows/Mac, стране и региону. IP, имена и идентификаторы посетителей не сохраняются. Повторные клики учитываются; блокировка JavaScript или запросов статистики может приводить к недоучёту. География зависит от доступности request.cf, VPN и сети посетителя. Это не число уникальных людей, завершённых скачиваний или установок.
6. История скачиваний — публичный GitHub API уже предоставляет download_count для каждого файла. На момент проверки v1.1.118: Windows 1, Mac 0. В админке эти счётчики показаны отдельно: все источники, без географии и уникальных пользователей. Их нельзя суммировать с кликами сайта.
7. Взаимодействие с сайтом — чтение главной страницы больше не записывает настройки релиза и не запускает синхронизацию платежей. Синхронизация сохранена при открытии защищённой админки. Изменение перевода одного языка не перезаписывает другой. Несохранённые изменения сохраняются при переключении разделов и языков, выход предупреждает о них.

## Основания решений

У админок нет единственного универсального обязательного стандарта. Использованы официальные рекомендации и продуктовые примеры:

- GOV.UK, группировка и минимизация вопросов: https://design-system.service.gov.uk/patterns/question-pages/
- Sanity, локализация полей одного объекта: https://www.sanity.io/docs/studio/localization
- Canny, администраторское управление идеями: https://help.canny.io/en/articles/3827592-managing-posts
- Google Analytics, file_download как событие нажатия ссылки: https://support.google.com/analytics/answer/9216061
- Cloudflare, доступные country/region метаданные запроса: https://developers.cloudflare.com/workers/runtime-apis/request/
- GitHub, download_count: https://docs.github.com/en/rest/releases/assets

Предварительное одобрение идей — решение для этого сайта и запроса владельца; не утверждается, что оно обязательно или является стандартной очередью Canny.

## Проверки и ограничения

TypeScript проходит. Девять тестов проходят, включая полный сценарий на локальной D1: права администратора, Origin, некорректный ввод, отмена/смена голоса, модерация, сохранение голосов, независимость переводов и агрегация кликов. Сборка проходит.

Полный lint не проходит из-за существующих замечаний в UI-обёртках, hooks и страницах. В изменённых API и модели замечаний нет. Прямые ссылки выхода из админки сохранены по существующему поведению; lint предпочитает Next Link. Ошибки не скрывались.

Аудит зависимостей выявил 30 замечаний (21 high, 9 moderate), присутствующих в исходном стеке. Firebase/Firestore относится к неиспользуемым здесь модулям Firestore (в сайте используется Auth); Vite/Miniflare/ws/undici — преимущественно инструменты локального запуска и сборки; image-size — серверная библиотека обработки изображений, пользовательские QR здесь ограничены PNG/JPEG/WebP/GIF и показываются unoptimized. Нельзя считать весь стек проверенным безопасным: обновление платформенных зависимостей и проверка публичного оптимизатора изображений остаются отдельной технической работой. Автоматическое audit fix --force предлагает несовместимые версии/понижение Firebase и не выполнялось.

Браузер заблокировал localhost в IAB и Chrome (`ERR_BLOCKED_BY_CLIENT`). Это ограничивает визуальную проверку локальной сборки. Не заявляется полное соответствие WCAG; проверены семантические подписи, кнопки и aria-pressed/aria-live на уровне кода, а ручные визуальные проверки выполняются только на доступных экранах.

Изменяется только сайт. Установленная версия виджета v1.1.118, настройки Windows и пользовательские файлы виджета не затрагиваются.
